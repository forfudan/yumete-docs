# helix keymap

helix's keys, as yumete has them with the
[Yumete flavour](flavor.md) off (`[keys] flavor = "off"`). At the flavour's
default level, `basic`, a few of these keys do something else and more keys
are bound; the flavour's page lists each one. Where yumete and helix differ
otherwise, see [Coming from helix](../from/helix.md).

Select mode (`v`) lists only the keys that run something else while the
selection is being extended. Every other key does what it does in Normal
mode, and a motion grows the selection instead of moving it.

Each menu lists the keys that open it.
